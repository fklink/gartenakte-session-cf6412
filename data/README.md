# Geodaten

- `map.osm` – vom Nutzer bereitgestellter OpenStreetMap-Export des Bereichs.
- `rosengarten-osm.json` – daraus für den schnellen Import abgeleitete Referenzdaten der Gartenkolonie Rosengarten.

Enthalten sind im abgeleiteten Datensatz 134 referenzierte Parzellenpolygone (1–135, ohne 125), fünf Wege, acht Außentore innerhalb oder auf der Koloniegrenze sowie zwei äußere Grenzpolygone.
